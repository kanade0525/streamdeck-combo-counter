# 天気キー（Stream Deck プラグイン）仕様書

## これは何か

キー1枚に**今の気温**と、**これから2時間のうちに降るか**を出す。降り出す前に色が変わる。

## なぜ作るか

時計やCPUと同じ「あれば見る」枠に落ちると価値が無い。**行動が変わる情報に絞る**。

- 降り出す前に色が変わる → 傘を持つ、洗濯物を取り込む、自転車をやめる
- 今の気温 → 上着の判断

逆に、週間予報・湿度・風速・気圧は入れない。見ても行動が変わらないので、
72×72 の面積を使う理由が無い。

## データ源

### Open-Meteo（主）

`https://api.open-meteo.com/v1/forecast`

- **APIキー不要・登録不要・無料**。非商用かつ1日1万リクエスト未満の範囲
- 10分間隔で叩いても1日144回なので、上限に対して2桁の余裕がある
- 取得するもの
  - `current=temperature_2m,weather_code,precipitation` … 現在の気温と天気
  - `minutely_15=precipitation` を8本 … **これから2時間の降水（15分刻み）**
  - `daily=temperature_2m_max,temperature_2m_min` … 今日の最高最低（表示切替用）
- `timezone=Asia/Tokyo` を付ける

### 気象庁（補助・第2段階以降）

`https://www.jma.go.jp/bosai/forecast/data/forecast/<地域コード>.json`

- 鍵不要。**日本語の予報文**（「夜遅く 雨 所により 雷を伴い 激しく 降る」）が取れる
- ただし気象庁が公開APIとして仕様を約束しているものではないので、**取得は1時間に1回まで**にし、
  取れなければ Open-Meteo だけで成立させる。落ちても壊れない位置に置く

## 画面（72×72）

```
┌────────────┐
│ 22.8°      │  ← 現在気温（大きく）
│    ☂       │  ← 天気アイコン（WMOコードから自前のSVG）
│ ▁▁▃▅▂▁▁▁   │  ← これから2時間の降水（15分×8本）
└────────────┘
```

- 文字も図形も **SVG を `setImage` で送る**。`setTitle` は使わない
- 天気アイコンは WMO weather code から自前で描く。外部の画像は取りに行かない

## 色（背景）

**降水の「これから」だけで決める。** 今降っているかどうかではない。

| 状態 | 背景 | 条件 |
| --- | --- | --- |
| 平常 | 暗い灰 | 2時間以内の降水予測が全て 0mm |
| 来る | 青 | **1時間以内**に 0.1mm 以上の予測がある |
| 降っている | 濃い青（強調） | 現在の降水が 0.1mm 以上 |
| 古い | 灰＋数字を薄く | 取得に失敗し、前回値を出している |

**取れなかった時に前回値をそのまま出さない**のが肝。古いと分からない天気は嘘と同じなので、
薄く表示して「これは古い」と見て分かるようにする。

## 押した時

このプラグインは「押して解決する」型ではない。押す動作は表示の切替に留める。

- 短押し … 表示を順に切替（現在気温 → 今日の最高最低 → 体感の一言）
- 長押し（1.5秒）… 手動で取り直す

## 設定（Property Inspector）

| 項目 | 既定 | 備考 |
| --- | --- | --- |
| 緯度・経度 | （空） | **手入力。位置情報の権限は取らない** |
| 表示名 | （空） | 地名。キー上部に小さく出す |
| 更新間隔 | 10分 | 最短5分 |
| 雨と判定する閾値 | 0.1mm | |
| 何分先まで見るか | 60分 | 色を変える判断に使う範囲 |

## 外に出るもの

- **緯度経度だけ**を Open-Meteo に送る。それ以外は何も送らない
- 座標は**小数2桁に丸めて**から送る（約1km四方。自宅を特定できる精度では出さない）
- 取得結果は端末内にのみ保持する

## 受け入れ条件

1. 起動直後に1回取得し、以後は設定した間隔で更新される
2. 通信を切ると「古い」表示になり、復帰すると次の更新で通常に戻る
3. 1時間以内に降水予測がある時だけ青くなる（2時間先にしか無い時は青くならない）
4. Stream Deck を再起動しても設定が残る
5. 別ページに切り替えて戻しても、表示が古いままにならない

## 作る順

| 段階 | 内容 |
| --- | --- |
| 1 | 固定座標で気温だけ取って描く |
| 2 | 15分刻みの降水バーと色 |
| 3 | 取得失敗時の「古い」表示 |
| 4 | Property Inspector |
| 5 | 表示切替（短押し） |

## 死活監視キーとの共有

常駐して定期的に叩き、結果をSVGで描き、失敗を状態として扱う骨格は同じ。
**取得部分と描画部分を共通のモジュールに置き、アクションごとに差し替える**形にする。
